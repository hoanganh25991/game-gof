# IMP0001 — Performance Optimization Plan

**Goal:** Stable 30+ FPS on mid-tier tablets (Xiaomi Redmi Pad 6) at Medium quality, with headroom toward 60 FPS on desktop. Measurable via the live FPS badge (top-right) and Settings → Info tab.

**Repo:** `game-gof` (ported from `game-got` IMP0001, adapted to coordinator architecture)

---

## 1. Current State

| Area | Status |
|------|--------|
| **Renderer** | Quality-tier pixel ratio; WebGL context handlers; GPU instancing for enemies |
| **GPU batching** | Instanced env props, fence, GPU collision bake |
| **VFX** | Split effect modules + `effects_base.js`; adaptive caps; FPS-based gating via `perf.js` |
| **CPU** | `SpatialGrid` in `enemies_system.js`, AI stride, frame budget, throttled HUD/minimap/FPS/mouse raycast |
| **LOD** | Enemy mesh LOD in `meshes.js`; env flower hide; device-tier profiles |
| **GC** | Joystick `moveTarget` reuse; camera temp vectors in `world.js` |
| **Measurement** | FPS badge; Settings → Info; `?profile=1` slow-frame warnings |
